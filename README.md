# CreatorOS 公开作品集部署版

本仓库使用代码内的固定生成数据启动，不附带原本地数据库、运营反馈、导出记录、日志或密钥。

## 公开运行

上传本仓库后，在Render中用New → Blueprint导入根目录render.yaml，或创建Docker Web Service。前后端同源运行，保留完整分析接口与交互。

本地可使用 `docker compose up --build`；或 `python app/server.py --no-browser` 打开 http://127.0.0.1:8787 。Python启动默认只监听本机，Docker中通过HOST环境变量监听0.0.0.0。自定义域名须填入PUBLIC_HOSTS，Render的默认域名自动识别；跨域写入仍被拒绝。

公开展示实例中请勿配置真实采集令牌、业务数据或模型密钥。多人访问共用当前实例的展示数据；默认不挂载付费磁盘，重启或重新部署可能重置。私有业务系统应独立部署并增加身份权限。

# CreatorOS｜创作者经营工作台

本地运行的创作者运营分析平台：经营总览、国家分析、创作者与内容详情、达人发现、加热与转化、运营任务、数据管理。

## 启动

安装 Python 3.10+，双击本目录 `start.bat`，打开 http://127.0.0.1:8787 。不需要安装第三方 Python 包、Node 或数据库服务。

启动会增量迁移 SQLite，保留已有创作者档案、运营任务和反馈。界面默认选择数据库最近的指标日期，重启不会按当前日期自动生成业务数据。

## 查看路径

经营总览 → 国家变化贡献 → 查看创作者 → 单条内容 → 评论词云、主题与样本。全局日期、平台和国家筛选在下钻时保留，顶部分析路径可返回。

在达人发现中调整推荐权重、收藏、填写负责人、更新联系状态，或转入试合作。在加热与转化中查看分币种费用、GMV、净GMV、用户增长、漏斗和明细。在创作者异常中创建运营任务，并保存执行反馈。

## 数据来源与接入状态

**预置的身份、内容、评论、候选达人及商业记录均为固定生成的作品集数据，不是三个平台实际抓取结果，也不代表任何真实公司的经营结果。** 页面使用正式业务文案，来源说明保留在开发文档中。已有生成数据的账号补齐至90个自然日的历史范围，保留两位账号的故意采集缺口以检查缺失拦截；新增真实账号不会自动补造历史。

已实现真实的本地查询、规则计算、持久化、CSV/JSON导入、Dataset适配、手动同步及Windows调度脚本。三平台的在线抓取、登录权限及订单系统连接尚需配置上游数据源，当前没有真实线上联调或采集成功的声明。

复制 `.env.example` 为 `.env`，填入访问令牌及各平台现有 Dataset ID。每条上游记录用 `record_type` 标注类型，字段映射为“上游字段名 → 内部字段名”。同步读取已存在的数据集；不自动购买采集服务或启动付费Actor。上游须自行执行合规的采集任务并更新Dataset。

- 手动：数据管理 → 同步已配置数据源，或运行 `python app/sync.py`。
- 每日：运行 `powershell -ExecutionPolicy Bypass -File .\schedule.ps1` 安装北京时间08:00调度；运行同一脚本加 `-Remove` 移除。脚本已提供，未自动安装系统任务。
- 加热页每60秒检查本地数据；这不代表上游每分钟更新。
- 失败记录写入处理日志；已成功导入的类型批次保留，重试以相同业务主键更新。单个类型批次原子写入，跨类型同步不构成一个数据库事务。
